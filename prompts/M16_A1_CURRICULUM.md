# M16 A1 Curriculum Blueprint

M16-A1-BLUEPRINT is an offline, development-only outline artifact. It consumes the immutable M15 knowledge-graph population and never mutates M2/M5. Edition-qualified IDs use `m16a1-v1-`. The blueprint contains no lesson prose, exercises, answer keys, or media. `OUTLINE_ONLY` is not approval or release evidence.

## Contract

A1.1 and A1.2 each contain five globally ordered units, five lesson outlines per unit, explicit objectives, grammar/vocabulary/function/pronunciation targets, prerequisites, review placements, and assessments. Every target resolves to an M15 node in the supplied population; only the A1.1/A1.2 subset is permitted. Validation is deterministic and offline.
