# 12.5D — German A1.1 Mini Blueprint

This is an outline-only German A1.1 planning artifact bound to the 12.5B German
bootstrap population. It contains exactly two units and ten lessons under `course/de/a1/`.
IDs are language-qualified (`de-a1-v1-uNN-lNN`) and targets are limited to the ten
`kg_de_a1_1_*` nodes.

The outline sequences first contacts, introductions, personal details, clarification,
and short guided exchanges. It models German-specific targets without translating the
English blueprint. Every target is introduced once, then practised or reviewed after
introduction. Final lessons in each unit are review lessons.

The artifact is `OUTLINE_ONLY`, original project-authored planning material. It contains
no lesson prose, exercises, answer keys, media, AI prompts, external payloads, source
content, generation authorization, human review, release approval, or official CEFR
endorsement. The German bootstrap remains a fixture-only graph and the source hash is
retained only for deterministic binding.

12.5E German lesson-pilot generation remains a separate, explicitly requested step.
