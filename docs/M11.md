# M11 — Export & Packaging

**Status:** Framework complete; production export blocked pending genuine complete human/release authority.

## Scope

M11 packages eligible learning content into:

- JSON
- CSV
- Static mobile resources
- Static web resources
- Printable HTML
- IMS Common Cartridge 1.3 (`.imscc`)

## Implementation

The export implementation is in [src/english_master/export_packaging/](../src/english_master/export_packaging/).

Available commands:

```bash
python -m english_master.export_packaging inspect-authority ...
python -m english_master.export_packaging build ...
python -m english_master.export_packaging verify ...
```

Exports are deterministic, hash-inventoried, independently verifiable, atomic, and no-overwrite. The exporter requires explicit release authority and an explicit export timestamp.

## Safety boundary

Current M6–M10 artifacts remain development evidence or `UNREVIEWED`. The current M9 sample is representative-only and M10 remains escalated. The real Tatoeba pilot is not curriculum material and is categorically excluded from exports.

Consequently, the current repository cannot produce a production export. The command fails closed until a complete, genuine human-reviewed and release-approved candidate exists. No human or release approval is inferred or fabricated.
