# M11 — Local Batch Export

## Active workflow

Build one explicitly declared local batch into JSON, CSV, static web, and static mobile files:

```bash
python -m english_master.export_packaging build-batch \
  --batch-input path/to/m11-export-batch-input.json \
  --repository-root . \
  --output-root data/exports \
  --exported-at <ISO-8601>

python -m english_master.export_packaging verify-batch \
  data/exports/<export-id> \
  --repository-root .
```

Add `--include-print` or `--include-ims` only when those formats are wanted.

The input validates artifact schemas, repository-safe paths, hashes, source redistribution permissions, a closed inventory, and consistent `UNREVIEWED` lifecycle status. Output rendering is deterministic and atomic/no-overwrite.

This local-batch path does not require M9 full-population review, M10 closure, `DEVELOPMENT_APPROVED`, human review, release authority, or paid AI. A successful export does not authorize public distribution or alter the underlying content lifecycle.

## Historical command

`inspect-authority`, `build`, and `verify` retain the earlier strict authority contract for historical immutable records. They are not required by the active local-batch workflow.
