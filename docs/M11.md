# M11 — Export & Packaging

**Status:** AI-only development export framework implemented but blocked. The repository has neither a complete version-2 full-population M9 batch nor closed M10 lineage.

## Scope

M11 packages eligible learning content into JSON, CSV, static mobile resources, static web resources, printable HTML, and IMS Common Cartridge 1.3 (`.imscc`).

The implementation is in [src/english_master/export_packaging/](../src/english_master/export_packaging/).

```bash
python -m english_master.export_packaging inspect-authority ...
python -m english_master.export_packaging build ...
python -m english_master.export_packaging verify ...
```

Exports are deterministic, hash-inventoried, independently verifiable, atomic, and no-overwrite. Active authorization requires a version-2 full-population `DEVELOPMENT_APPROVED` M9 batch, the source registry, an exact 10-lesson/10-exercise-set/40-prompt inventory, and an explicit export timestamp. It does not request, infer, or record human review, endorsement, or release approval.

## Safety boundary

M9 development evidence is a development-quality claim only. M11 requires every selected generated artifact to remain consistently `UNREVIEWED`; coverage by exact passing evidence is the gate and does not relabel content. Representative version-1 M9 evidence, missing or mixed lifecycle fields, incomplete 10/10/40 inventories, and non-promotable capture lineage fail closed. The prepared historical M9 selection is not a completed development batch, and the current immutable M10 escalation remains unresolved, so this repository is not currently eligible.

M11 independently reconstructs the current M5–M8.2 authority, verifies the complete M9 directory rather than trusting its batch envelope alone, and compares export members one-to-one with all reviewed subjects. It also conservatively rejects any recorded unresolved M10 run. A future versioned hash-bound M10 lineage-closure input is still recommended before resolved/superseded M10 histories are exportable.

The real Tatoeba pilot is not curriculum material and is categorically excluded. Historical human/release artifacts remain untouched and cannot satisfy the active M11 authorization schema.
