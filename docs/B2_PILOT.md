# B2 Pilot

This bounded pilot derives exactly ten lessons (the first two B2.1 units) from the M16 blueprint. The CLI builds immutable packets, verifies hashes and references, emits a deterministic PASS audit, and creates a SHA-256-ranked five-lesson sample. It is original-authored, `UNREVIEWED`, offline, and contains no external media or release authority.

Run `python -m english_master.b2_pilot --help`.
